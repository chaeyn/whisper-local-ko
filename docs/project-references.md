# Project references

Reviewed on 2026-10-02.
These projects informed the release documentation and contribution workflow.
Their source code and documentation text were not copied into this project.

## Buzz

Chidi Williams authored Buzz's [initial commit](https://github.com/chidiwilliams/buzz/commit/e604518c30be1f64011778df8fdcbbf277330ec7) on 2022-09-24.
The project now has multiple contributors.
Its [README](https://github.com/chidiwilliams/buzz/blob/100589fd8c492869f2994b525e1092eda81e4e88/README.md) separates features and installation instructions by operating system.
Its [contribution guide](https://github.com/chidiwilliams/buzz/blob/100589fd8c492869f2994b525e1092eda81e4e88/CONTRIBUTING.md) covers translations, diagnostic details, and platform setup.

We applied these lessons:

- Put the local speech workflow before installation details.
- Give each supported OS its own installation procedure.
- State architecture limits beside the supported environments.
- Ask bug reporters for versions, selected settings, and reproduction steps.
- Explain how contributors update translated documents.

Buzz supports workflows and backends that this project does not implement.
Its feature list is not a support claim for Whisper Local KO.

## Lazygit

Jesse Duffield authored Lazygit's [initial commit](https://github.com/jesseduffield/lazygit/commit/4f2b1608b4dd61f85f4eda3dd2492a2d27fc9558) on 2018-05-13.
Its [README](https://github.com/jesseduffield/lazygit/blob/ff375b124d149f03f9156d3720a998cbc04482fa/README.md) explains keyboard workflows and separates installation routes.
The reviewed [contribution guide](https://github.com/jesseduffield/lazygit/blob/ff375b124d149f03f9156d3720a998cbc04482fa/CONTRIBUTING.md) explicitly declines pull-request merges.
It invites bug reports, reproduction help, translation work, and testing of development builds.

We applied these lessons:

- Document the keys next to the task they perform.
- State the accepted contribution types and review limits.
- Ask reporters to answer follow-up questions.
- Treat reproducible failures and user testing as contributions.

Whisper Local KO accepts pull requests under its own [contribution policy](../CONTRIBUTING.md).
The reference project has a different maintenance policy.
Pinned links preserve the reviewed version because project policies can change.

## ASD-STE100

The [official overview](https://www.asd-ste100.org/about_STE.html) describes writing rules, a controlled dictionary, and consistent technical terms.
Our [writing guide](writing-guide.md) applies short instructions, active voice, and consistent terminology.
The Korean documents apply the same clarity principles through project-specific Korean rules.
This is an inspired style, not a claim of formal STE conformance or an official Korean adaptation.
